# 通常版の通知音候補

作成: 2026-10-28 JST。いずれも未採用の試聴候補。

## 聴き比べる順番

1. 同じ再生音量で「ころん」「きらり」「ぴこん」を1つずつ再生する。
2. 気づきやすさ、驚かないか、何度聞いても疲れないかを比べる。
3. 気に入った方向を選び、必要なら高さ・長さ・余韻を調整する。

| 候補 | ファイル | 長さ | 狙い |
| --- | --- | --- | --- |
| A ころん | `01-koron.wav` | 1.12秒 | 丸い音色の2音。落ち着いた呼びかけ |
| B きらり | `02-kirari.wav` | 1.42秒 | 少し明るいベルの2音。短い余韻 |
| C ぴこん | `03-pikon.wav` | 0.96秒 | 滑らかに上がる電子音。少し遊びのある呼びかけ |

48 kHz・16-bit PCM・モノラルWAV。音声や録音素材を使わず、このプロジェクト用に波形を合成した。先頭と末尾を滑らかにし、ピークを -12 dBFS 以下に抑えている。再生機器の実際の音量や聞こえ方は、試聴で判断する。

生成元は `tools/generate_notification_sounds.py`。Python標準ライブラリだけで再生成できる。既存のWAVは上書きしないため、再生成時は `--output` で別の候補フォルダを指定する。

アプリの既定音にはまだ設定していない。今回の生成は通知音候補の作成までで、再通知タイマーやGoogle接続は変更しない。

## 検証

出力WAVを開き直し、形式・長さ・先頭と末尾のゼロ・ピーク・直流成分を確認した。RMSは3候補とも約 -25 dBFS、ピークは順に -12.48 / -12.08 / -13.78 dBFS。音質や聞こえ方の受け入れはユーザーによる試聴で行う。自動再生、アプリへの組み込み、実スピーカーでの聴感確認はしていない。
